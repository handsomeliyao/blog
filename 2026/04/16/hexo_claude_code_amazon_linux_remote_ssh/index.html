Amazon Linux 上通过 VS Code Remote SSH 远程使用 Claude Code 完整指南

很多人第一次接触 Claude Code 时，会下意识地想：能不能把它部署在 VPS 上，然后本地电脑像访问一个网页服务一样去使用？

对于这个需求，更合适、也更稳的实现方式并不是把 Claude Code 做成一个公网 Web 服务，而是：

  • Claude Code 安装在 Amazon Linux 云服务器上
  • 项目代码放在云服务器上
  • 本地电脑通过 VS Code 的 Remote SSH 连接远程主机
  • 在本地 VS Code 中直接打开远程项目目录
  • Claude Code 实际运行在远程服务器环境中

这种方式更符合 Claude Code 的使用形态，也更适合长期开发、调试和部署。

Anthropic 官方文档说明，Claude Code 提供了 VS Code 原生扩展，这是在 VS Code 中使用 Claude Code 的推荐方式；扩展还包含 CLI，可直接在 VS Code 集成终端中使用。citeturn150083search0

一、为什么推荐这种方案

这个方案的核心价值在于：开发入口在本地，执行环境在远端。

也就是说：

  • 你本地看到的是 VS Code 图形界面
  • 你编辑的是服务器上的真实项目文件
  • Claude Code 读取、修改、执行命令的环境也是服务器
  • 不需要额外给 Claude Code 暴露公网端口

这样做有几个明显好处：

1. 环境统一

很多项目都有“本地能跑、服务器不能跑”的问题。把代码、依赖、运行环境都放在 Amazon Linux 服务器上后，Claude Code 处理的就是最终真实环境。

2. 更适合远程开发

如果你的项目本来就部署在 EC2、VPS 或远程 Linux 主机上，这种方式几乎就是最自然的工作流。

3. 本地电脑压力更小

依赖安装、命令执行、日志分析都在远程服务器进行，本地主要承担编辑器界面的角色。

4. 安全性更高

Claude Code 本身并不是一个典型的公网服务程序。通过 SSH 或 VS Code Remote SSH 使用，比额外套一层网页服务更稳妥。

二、先决条件

在开始之前，先确认你具备以下条件。

本地电脑需要准备

  • 已安装 VS Code
  • 本地网络可以稳定连接服务器
  • 能正常使用 SSH
  • 有浏览器可用于 Claude Code 首次登录授权

云服务器需要准备

  • Amazon Linux 2 或 Amazon Linux 2023
  • 可 SSH 登录
  • 有普通用户账号
  • 可以正常联网访问 Claude 登录和相关服务
  • 已经准备好项目目录，或者计划把项目放到服务器上

Claude Code 账号要求

Claude Code 需要可用的 Anthropic 账号计划。首次打开扩展或首次运行 CLI 时需要登录。citeturn150083search0turn150083search1

十一、如何在 Remote SSH 环境里使用 Claude Code

在这个阶段，主要有两种使用方式。

方式一：直接使用 Claude Code 扩展

这是 Anthropic 官方推荐的 VS Code 集成方式。扩展可以提供：

  • 图形化面板
  • 对话入口
  • 和当前项目上下文联动
  • 和编辑器联动
  • CLI 能力

使用步骤通常是：

  1. 确保当前窗口已经通过 Remote SSH 连接到远程服务器
  2. 确保你打开的是远程项目目录
  3. 启用 Claude Code 扩展
  4. 根据提示完成登录
  5. 开始在 VS Code 中直接使用 Claude Code

如果你发现扩展“本地可见，但远程窗口不可用”，要重点检查扩展是否安装或启用在 SSH 远程主机环境 中，而不是只安装在本地窗口中。

十五、安全建议

这里要特别强调一点：不要把 Claude Code 当成一个直接对公网开放的 Web 服务去部署。

更稳妥的做法始终是：

  • 只通过 SSH 或 VS Code Remote SSH 进入
  • 不额外开放 Claude Code 公网端口
  • 尽量使用普通用户而不是长期 root
  • 对项目目录做合理权限控制
  • 对敏感仓库检查 Claude Code 权限配置

Anthropic 官方安全文档也建议对敏感仓库使用更严格的权限控制，并可通过 /permissions 检查相关设置。citeturn150083search4

十六、常见问题排查

1. claude: command not found

先执行：

再重点检查：

  • 是否刚安装完但没重新登录
  • VS Code Remote SSH 终端是否加载了用户 shell 配置
  • 安装路径是否被加入 PATH

2. 登录页面没有在本地浏览器弹出

这是很常见的情况，原因通常是你在远程 SSH 终端里执行了 claude，浏览器打开动作发生在远程服务器而不是本地电脑。

处理方式很简单：

  • 复制终端给出的登录 URL
  • 手动粘贴到本地浏览器打开
  • 完成授权即可

3. VS Code 里看得到扩展，但远程窗口用不了

优先检查：

  • 当前窗口是不是 Remote SSH 窗口
  • Claude Code 扩展是否安装在“远程 SSH 主机环境”
  • 是否只是装在本地环境

十八、总结

对于“我想把 Claude Code 放在 Amazon Linux 服务器上，然后本地通过 VS Code 使用它”这个需求，最合理的实现方式就是：

Claude Code 安装在服务器，本地通过 VS Code Remote SSH 打开远程项目，然后使用 Claude Code 扩展或在远程终端运行 claude。

它的本质不是公网部署，而是：

  • 远程服务器承担运行环境
  • 本地 VS Code 承担操作入口
  • 代码、依赖、命令执行全部都在服务器端完成

这种方式更稳定，也更接近 Claude Code 官方推荐的使用路径。citeturn150083search0turn150083search1turn150083search3
