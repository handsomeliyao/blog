背景

2026 年 3 月 6 日，我在 OpenClaw Control UI 中向我的 AI 助手提出了一个需求：帮我开发一个获取天气信息的 Skills，主要使用 Open-Meteo API。

这篇文章完整记录了从需求提出到最终实现的整个开发过程，包括技能设计、API 集成、定时任务配置等细节。

需求分析

初始需求

帮我开发一个获取天气信息的 skills，主要使用 https://open-meteo.com/en/docs

核心需求：

  1. 查询实时天气信息
  2. 支持天气预报
  3. 使用 Open-Meteo 免费 API（无需 API key）
  4. 中文输出

扩展需求

在开发过程中，逐步添加了以下功能：

  1. 当日最高/最低温度显示
  2. 每天早上 8:20 自动推送上海天气到 Telegram
  3. 使用 OpenClaw 原生 cron 定时任务

经验总结

技能设计原则

  1. 简洁优先 - SKILL.md 保持精简，详细资料放入 references
  2. 渐进式加载 - 元数据始终加载，正文触发后加载，参考资料按需加载
  3. 可复用性 - 脚本设计支持参数化，方便不同场景调用

Open-Meteo API 使用技巧

  1. 坐标精度 - 小数点后 4 位足够（约 10 米精度）
  2. 时区处理 - 使用 timezone=auto 自动返回本地时间
  3. 速率限制 - 免费用户约 10,000 次/天，足够个人使用

OpenClaw Cron 最佳实践

  1. isolated 模式 - 避免污染主会话历史
  2. announce 推送 - 直接发送到目标渠道，无需额外消息工具
  3. lightContext - 简单任务可启用轻量级上下文

  1. 多城市支持 - 允许用户配置多个关注城市

  3. 历史数据 - 使用 Open-Meteo Historical API
  4. 语音播报 - 结合 TTS 生成天气语音简报
