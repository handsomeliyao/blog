OpenClaw 整合 WhatsApp 和 Telegram 完整教程

📖 前言

OpenClaw 是一个强大的 AI 助手框架，可以连接多种聊天平台。本教程将详细介绍如何将 OpenClaw 与 WhatsApp 和 Telegram 进行整合，让你可以通过这两个主流通讯工具与 AI 助手进行交互。

🎯 环境准备

系统要求

  • 操作系统: Linux (推荐 Ubuntu 20.04+ 或 Amazon Linux 2023)
  • Node.js: v18.0 或更高版本
  • npm: v8.0 或更高版本
  • OpenClaw: 2026.3.1 或更高版本

步骤 4：扫描二维码

📱 第二部分：Telegram 集成

步骤 1：创建 Telegram Bot

  1. 在 Telegram 中搜索并打开 @BotFather
  2. 发送命令 /newbot
  3. 按提示输入：
    • Bot 名称: 如 MyOpenClawBot
    • Bot 用户名: 必须以 bot 结尾，如 my_openclaw_bot
  4. 保存 BotFather 返回的 Token (格式类似：123456789:ABCdefGHIjklMNOpqrsTUVwxyz)
